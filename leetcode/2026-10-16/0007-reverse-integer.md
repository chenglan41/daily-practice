# 7. 整数反转 (Reverse Integer)

- 难度：中等 · 日期：2026-10-16
- 链接：https://leetcode.cn/problems/reverse-integer/
- 结果：**通过 1046/1046 用例，0 ms 击败 100.00%**，内存 8.50 MB

## 思路（边反转边判溢出）

题目禁止用 64 位整数，所以**必须在乘 10 之前**判断会不会越界：

1. 每次取末位 `d = x % 10`，`x /= 10`；
2. 在 `r = r * 10 + d` 之前检查：
   - 上溢：`r > INT_MAX / 10`，或 `r == INT_MAX / 10 && d > 7`（因为 `INT_MAX = 2147483647`，末位是 7）；
   - 下溢：`r < INT_MIN / 10`，或 `r == INT_MIN / 10 && d < -8`（`INT_MIN = -2147483648`，末位是 -8）；
3. 越界直接返回 0。

**易错点**：判断必须放在乘法之前；`INT_MAX` 末位 7、`INT_MIN` 末位 -8 这两个"边界边界"最容易漏。
C++ 里 `x % 10` 对负数得到负数，这让正负两种情况可以统一处理。

## 代码（C++）

```cpp
class Solution {
public:
    int reverse(int x) {
        int r = 0;
        while (x != 0) {
            int d = x % 10;
            x /= 10;
            if (r > INT_MAX / 10 || (r == INT_MAX / 10 && d > 7)) return 0;
            if (r < INT_MIN / 10 || (r == INT_MIN / 10 && d < -8)) return 0;
            r = r * 10 + d;
        }
        return r;
    }
};
```
