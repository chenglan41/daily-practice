# 9. 回文数 — Easy

- 题目: https://leetcode.cn/problems/palindrome-number/
- 语言: C++
- 提交结果: **AC 11513/11513**，执行用时 **0 ms（击败 100.00%）**，内存 8.43 MB
- 提交时间: 2026-10-16 23:19

## 思路
只反转**一半**数字，避免整型溢出：
- 负数直接 false；末位为 0 且非 0 的数（如 10）也 false；
- 循环条件 \x > rev\ 正好停在中点；
- 偶数位 \x == rev\，奇数位 \x == rev / 10\。

## 本地验证
同算法用 Python 跑 **13 个用例**（含 0、1、INT_MAX、-101、1000021、2147447412），全部通过。
