# 8. 字符串转换整数 (atoi)

- 难度：中等 · 日期：2026-10-16
- 链接：https://leetcode.cn/problems/string-to-integer-atoi/
- 结果：**通过 1096/1096 用例，0 ms 击败 100.00%**，内存 8.93 MB 击败 82.09%

## 思路

严格按题面四步走，一次遍历：

1. **跳过前导空格**：`while (i < n && s[i] == ' ') ++i;`
2. **取符号**：`+`/`-` 只认**第一个**，取完 `++i`；都没有就当正数
3. **连续读数字**：遇到非数字立刻停（后面内容全部忽略）
4. **溢出截断**：一边累加一边判，超了立刻返回 `INT_MAX` / `INT_MIN`

**关键技巧**：用 `sign` 决定上限 `LIMIT`——
正数上限 `2147483647`，负数上限 `2147483648`（因为 `-2147483648` 是合法的），
这样 `-91283472332` 和 `2147483648` 两个方向都能正确处理。

## 复杂度

- 时间 **O(n)**，空间 **O(1)**

## 代码（C++）

```cpp
class Solution {
public:
    int myAtoi(string s) {
        int i = 0, n = s.size();
        while (i < n && s[i] == ' ') ++i;
        int sign = 1;
        if (i < n && (s[i] == '+' || s[i] == '-')) {
            if (s[i] == '-') sign = -1;
            ++i;
        }
        long long val = 0;
        const long long LIMIT = (sign == 1) ? 2147483647LL : 2147483648LL;
        while (i < n && s[i] >= '0' && s[i] <= '9') {
            val = val * 10 + (s[i] - '0');
            if (val > LIMIT) return (sign == 1) ? INT_MAX : INT_MIN;
            ++i;
        }
        return (int)(sign * val);
    }
};
```

## 本地验证（g++ 16.2.0，2017/2017 通过）

参照实现**故意换一条路**（切出数字子串 → `stoll` + clamp），不是抄题解自己：

| 输入 | 输出 | 考点 |
|---|---|---|
| `42` / `   -42` | 42 / -42 | 基本 + 符号 |
| `4193 with words` | 4193 | 遇非数字停 |
| `words and 987` | 0 | 一开始就不是数字 |
| `-91283472332` | -2147483648 | 下溢截断 |
| `2147483648` | 2147483647 | 上溢截断 |
| `-2147483648` | -2147483648 | **边界值必须保留** |
| `+-12` / `  +  413` | 0 / 0 | 符号只能有一个 |
| `00000-42a1234` | 0 | 前导零后遇 `-` |
| `9223372036854775808` | 2147483647 | 超 long long 也不崩 |

外加 **2000 组随机串**与参照实现对拍，全部一致。

## 踩坑

- `+-12`：符号**只认第一个**，第二个符号视为非数字 → 返回 0
- 累加时必须**每步判溢出**，不能等全部读完（`9223372036854775808` 会撑爆 `long long`）
- 负数的上限比正数大 1（`-2147483648` 合法），别用同一个界限
