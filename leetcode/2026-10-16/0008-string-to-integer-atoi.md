# 8. 字符串转换整数 (atoi) — Medium

- 题目: https://leetcode.cn/problems/string-to-integer-atoi/
- 语言: C++
- 提交结果: **AC 1096/1096**，执行用时 **0 ms（击败 100.00%）**，内存 9.11 MB
- 提交时间: 2026-10-16 23:23

## 思路
按题意四步走，边读边判溢出：
1. 跳过前导空格；
2. 读符号（+/-，默认正）；
3. 逐位读数字，用 \long long\ 累加，**每位都检查是否越界**，越界立刻返回边界值；
4. 返回 \sign * num\。
不用任何库函数转换（题目禁止）。

## 本地验证
用 Python 复刻同一算法跑了 **21 个用例**（含 \"  -0012a42"\、\"+-12"\、\"2147483648"\、
\"-2147483649"\、\"  0000000000012345678"\、\"3.14"\ 等边界），**全部通过**。
